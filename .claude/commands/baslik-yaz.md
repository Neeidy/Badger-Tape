Lofi Girl analizini (lofi-girl-analiz.md) referans alarak Badger Tape için YouTube başlığı, açıklaması ve tag listesi üret.

Kullanıcıdan şunları al (belirtilmemişse makul varsayılanlar kullan):
- **Tema**: (örn. yağmurlu gece, kış sabahı, sonbahar, uyku, odaklanma)
- **Süre**: (örn. 1 saat, 3 saat, 8 saat)
- **Format**: (standart miks / uyku / çalışma / pomodoro / mevsimsel / POV)

Ardından şu formatta 3 başlık seçeneği + açıklama + tag listesi üret:

---

## Başlık Seçenekleri (3 Adet)

Lofi Girl kurallarına uy:
- küçük harf (özel isimler hariç)
- emoji kullan (tematik)
- "beats to [verb] to" imzasını kullan
- süreyi köşeli parantezde belirt: `[1 hour]`
- POV formatı varsa "pov: you..." ile başla

**Seçenek A** (klasik format):
```
{tema} lofi {emoji} [süre] beats to {aktivite} to
```

**Seçenek B** (atmosfer/zaman formatı):
```
{saat/atmosfer} with badger tape {emoji} [süre] {müzik türü} for {aktivite}
```

**Seçenek C** (POV format — yüksek performans):
```
pov: {empati kuran senaryo} {emoji} lofi beats to {aktivite} to
```
